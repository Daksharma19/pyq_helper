# Phase 4: Question extraction and search

Read `CLAUDE.md` and the existing code. Plan first, then build.

**Goal:** papers are broken into individual questions that students can search.

- Extract each question (number, text, marks, and topic or CO tag where present) from approved papers, including the existing backlog. Check that question marks add up to the paper's total.
- Let admins correct extracted questions.
- Question search across all papers, filterable by course, term and year, with links back to the source paper.
- Show which questions repeat across years for a course, grouping near-identical wording.

Done when a student can search "Karnaugh map" for Digital Systems and see every past question on it, with repeats grouped.
